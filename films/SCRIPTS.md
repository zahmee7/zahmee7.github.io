# سيناريوهات الأفلام

```
Film scripts · MVP (3 films)
```

## القواعد العامة

- مدة الفيلم الكامل بين ٤٥ و ٦٠ ثانية.
- مقطع الحلقة القصير بين ٦ و ٨ ثوانٍ، بدون نص، ويُقتطع من مشهد في الفيلم نفسه. هذا المقطع يعمل تلقائياً داخل الملف قبل الضغط على تشغيل.
- لا يوجد تعليق صوتي. نص قصير على الشاشة مع موسيقى هادئة مرخّصة، حتى يُفهم الفيلم وهو صامت.
- نسختان من كل فيلم، عربية وإنجليزية، من نفس المشروع مع تبديل النصوص فقط.
- الألوان والخط من ملف الرموز التصميمية، والعنصر البصري الأساسي هو الورق والمجلدات والمربعات المضيئة.
- ممنوع في أي لقطة: رقم خاص بالجهة، أو شعار، أو لقطة من نظام داخلي، أو اسم شخص.
- كل الأرقام والرسوم في الأفلام افتراضية ومدوّرة.
- النصوص المكتوبة في الجداول أدناه هي نفسها النص المقروء الذي يظهر تحت الفيلم في الموقع، لمن لا يشاهد الفيديو.

## مواصفات التصدير

| Item | Spec |
|---|---|
| Master | 1920×1080, 30 fps, ProRes or high-bitrate H.264 |
| Mobile cut | 1080×1350 (4:5), same timing, text re-laid for portrait |
| Loop | 6–8 s, seamless, no text, no audio, 1280×720 |
| Web film | `film.mp4` H.264 ≤ 12 MB · `film-av1.mp4` AV1 ≤ 8 MB, per minute of film |
| Web loop | `loop.mp4` H.264 ≤ 1.5 MB · `loop-av1.mp4` AV1 ≤ 1 MB |
| Poster | `poster.png` 1920×1080 (the build converts it to AVIF/WebP) |
| Audio | AAC 128 kbps, around −16 LUFS |
| Language | `-en` and `-ar` versions of film and poster |

التصدير والضغط بأمر واحد. ضع الملفات الأصلية في مجلد المشروع بهذه الأسماء، ومقطع الحلقة بلا نص اختياري:

```
films/<project-id>/master-en.mp4
films/<project-id>/master-ar.mp4
films/<project-id>/loop-master.mp4
```

ثم شغّل:

```
npm run films
```

الأمر يصنع الفيلم بصيغتين لكل لغة، ومقطع الحلقة، والصورة الثابتة، ثم يتأكد من الأحجام أعلاه. إذا لم يوجد مقطع حلقة منفصل، يُقتطع من النسخة الإنجليزية عند بداية المشهد الثالث.

نصوص المشاهد وتوقيتها محفوظة أيضاً في ملف المحتوى، ومنها تُصنع الترجمة والنص المقروء تحت الفيلم. إذا تغيّر توقيت مشهد في الفيلم الحقيقي، يُعدَّل هناك:

```
content/projects.json → film.scenes
```

الأدوات المقترحة، واحدة منها تكفي:

```
After Effects  (+ LottieFiles plugin for Lottie exports)
Jitter         (browser motion design, exports MP4 and Lottie)
Figma          (storyboard frames before animating)
```

## الفيلم ٣: لوحة أداء المؤشر الوطني للبيانات

```
executive-dashboard · 100 s · Arabic only · loop from scene 9
```

فيلم من صنع المالك نفسه بالعربية (٢٠٢٦-١٠-٢٥)، وهو يحل محل السيناريو المخطط سابقاً. الصفحة الإنجليزية تعرض نفس الفيلم، والترجمة الإنجليزية تعمل فيها تلقائياً. النصوص الكاملة بتوقيتها في ملف المحتوى، ومنه تُبنى الترجمة والنص تحت الفيلم:

```
content/projects.json → executive-dashboard → film.scenes
```

| # | Time | المشهد |
|---|---|---|
| 1–5 | 0–19 | ملفات وأدلة ومصفوفات متداخلة، وجهد طوال العام ونتيجة لا تُعرف إلا عند إعلانها. |
| 6 | 19–23 | التحديات: تعدد المتطلبات، غياب الرؤية الموحدة، صعوبة تقدير النتيجة وتحديد الأولويات. |
| 7–8 | 23–38 | الفكرة: معايير الوثيقة في مرجع واحد، تتحول إلى منظومة متابعة موحدة. |
| 9–11 | 40–58 | تصوّر مبكر للنتيجة، وسجل الدورات، وأين تقف الجهة. |
| 12–14 | 58–77 | النضج والامتثال والتميز التشغيلي بالتفصيل. |
| 15–17 | 77–95 | تناسب كل جهة، وتفاصيل للمختص ورؤية لصانع القرار، ومتابعة طوال العام. |
| 18 | 95–100 | بطاقة الختام. |

## بطاقة الختام (لكل الأفلام)

- ثلاث ثوانٍ ثابتة.
- عنوان المشروع، ثم نص الزر، ثم الاسم في الأسفل.
- نفس خلفية الموقع الكحلية، والزر بلون الورق.

## ترتيب العمل المقترح

١. ارسم لوحة القصة بإطار واحد لكل مشهد.

٢. ابنِ الفيلم الأول كاملاً بالإنجليزية.

٣. بدّل النصوص وصدّر النسخة العربية.

٤. اقتطع مقطع الحلقة.

٥. ضع الملفات الأصلية في مجلد المشروع، ثم شغّل أمر التصدير المذكور في مواصفات التصدير:

```
films/<project-id>/
npm run films
```
