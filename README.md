# Project Files · Mohammed Alzahmah

## بالعربي

هذا المجلد هو نقطة البداية لموقع أعمالك بتصميم خزانة الملفات، ومهارات التصميم مثبتة داخله.

افتح المجلد في الطرفية ثم شغّل الأمر التالي:

```
claude
```

أول مرة سيسألك إن كنت تثق بالمجلد، وافق. بعدها سيعرض تثبيت إضافة التصميم الرسمية، وافق أيضاً.

للتأكد أن كل المهارات ظاهرة، اكتب داخل الجلسة:

```
/skills
```

الموجز والتصميم معتمدان. خطة العمل ورسائل المراحل جاهزة، والنموذج التفاعلي جاهز. للبدء بالمرحلة الأولى، انسخ رسالتها من هذا الملف:

```
docs/PROMPTS.md
```
