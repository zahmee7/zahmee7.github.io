# النسخ التجريبية: ملفات المشاريع نفسها

```
Demos · the project's own file, in a sample version
```

صفحة التجربة لكل مشروع تعرض ملف المشروع نفسه ببيانات افتراضية: تقرير باور بي آي، أو ملف إكسل، أو ملف بي دي إف. الملف لا يُحمَّل حتى يضغط الزائر «افتح الملف الحي».

---

## ما ترسله لكل مشروع

| المشروع | نوع الملف | ما ترسله |
|---|---|---|
| لوحة المتابعة التنفيذية | تقرير باور بي آي | رابط النشر للعامة |
| متتبع الجاهزية | ملف إكسل | رابط التضمين من ون درايف، أو الملف نفسه |
| تصنيف البيانات | ملف بي دي إف | الملف نفسه |

إذا كان للتقرير أو الملف نسخة عربية وأخرى إنجليزية، أرسل الاثنتين، وكل لغة في الموقع تعرض نسختها.

## قبل أن ترسل أي ملف

- **بيانات افتراضية فقط:** اسم الجهة «الجهة التجريبية»، وأرقام مدوّرة، ولا أسماء أشخاص، ولا شعارات، ولا أسماء أنظمة داخلية.
- **انشر من حسابك الشخصي في مايكروسوفت، لا من حساب جهة عملك.** الرابط العام يبقى مرتبطاً بالحساب الذي نشر منه.
- **أفحص كل ملف قبل وضعه في الموقع،** وأنبهك إلى أي اسم أو رقم حقيقي.

---

## تقرير باور بي آي: النشر للعامة

١. افتح التقرير في خدمة باور بي آي على الإنترنت.

٢. من القائمة اختر:

```
File → Embed report → Publish to web (public)
```

٣. اضغط:

```
Create embed code → Publish
```

٤. انسخ **الرابط** وحده، لا كود التضمين. يبدأ هكذا:

```
https://app.powerbi.com/view?r=
```

٥. أرسله لي.

ملاحظات:

- أي شخص معه الرابط يرى التقرير وبياناته، لذلك البيانات الافتراضية شرط.
- إذا لم يظهر الخيار، فقد يكون النشر للعامة مقفلاً في الحساب، أو يحتاج ترخيصاً أعلى. الإعداد اسمه:

```
Admin portal → Tenant settings → Publish to web
```

- إذا عدّلت التقرير بعد النشر، يتحدّث في الموقع تلقائياً بنفس الرابط.

## ملف إكسل

### الطريقة الأولى (مستحسنة): التضمين من ون درايف

يعمل فوراً، ويستطيع الزائر التصفية والكتابة في الخلايا بدون أن يتغير ملفك.

١. ارفع الملف إلى ون درايف في حسابك الشخصي.

٢. اضغط على الملف بالزر الأيمن، ثم اختر:

```
Embed → Generate
```

٣. في خيارات التفاعل فعّل:

```
Let people type in cells (changes won't be saved)
```

٤. انسخ كود التضمين وأرسله لي، وأنا آخذ منه الرابط.

### الطريقة الثانية: الملف على الموقع نفسه

أرسل لي الملف، فأضعه في الموقع، ويُعرض بعارض مايكروسوفت على الإنترنت. هذا العارض لا يعمل إلا بعد نشر الموقع، والزائر يتصفح ولا يعدّل. ويمكن تحميل الملف من نفس الصفحة.

---

## ملف بي دي إف

أرسل لي الملف، فأضعه في الموقع، ويُعرض بعارض المتصفح نفسه مع رابط تحميل.

---

## بعد أن ترسل

أفحص الملف، ثم أضع نوعه ورابطه في ملف محتوى المشاريع، فيصير زر التجربة في الملف رابطاً حقيقياً:

```
content/projects.json → demo: { status: "ready", kind, url }
```

وأنواع الملفات المقبولة هناك:

```
powerbi · excel-onedrive · excel-viewer · pdf
```
