# خطوات النشر

```
Deploy setup · GitHub Pages · alzahmah.com · thmanyah fonts from a private repository
```

**الحالة:** الموقع منشور على الدومين منذ ١٣ أكتوبر ٢٠٢٦، وكل رفع إلى الفرع الرئيسي ينشره من جديد. الخطوات أدناه نُفذت، وتبقى هنا للمرجع ولتجديد المفتاح.

هذه الخطوات تنفذها أنت على حسابك في موقع GitHub، لأنها تتعلق بمستودعاتك ومفاتيحك. لا أحتاج أن أرى المفتاح، ولا تكتبه لي في المحادثة. ورفع ملفات الخط إلى مستودعها الخاص ترفعه أنت أيضاً: نظام الصلاحيات عندي يمنعني من إرسالها.

## ما هو جاهز

- مستودع الموقع موجود على حسابك، وعليه الآن صفحة مؤقتة تحوّل إلى البطاقة:

```
zahmee7.github.io
```

- الدومين مسجل في كلاودفلير، وسجلاته موجهة إلى GitHub، ومربوط بالمستودع:

```
alzahmah.com
```

- البطاقة الرقمية في مستودعها، على المسار:

```
https://alzahmah.com/card/
```

- المسار القديم للبطاقة يحوّل إليها، وأبقيته في الموقع حتى لا تتعطل الروابط القديمة:

```
/mohammed-card/
```

## ١. مستودع الخط الخاص

أنشئ مستودعاً **خاصاً** بهذا الاسم:

```
thmanyah-fonts
```

وارفع إليه الملفات الثلاثة فقط، في أول المستودع وليس داخل مجلد:

```
thmanyahserifdisplay-Bold.woff2
thmanyahsans-Regular.woff2
thmanyahseriftext-Regular.woff2
```

تجدها على جهازك هنا:

```
src/assets/fonts/thmanyah/
```

## ٢. مفتاح القراءة

أنشئ مفتاحاً محدود الصلاحية من إعدادات حسابك:

```
Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
```

واضبطه هكذا:

```
Repository access: Only select repositories → thmanyah-fonts
Permissions → Repository permissions → Contents: Read-only
Expiration: 1 year
```

انسخ المفتاح مرة واحدة، فالموقع لا يعرضه مرة ثانية.

## ٣. حفظ المفتاح في مستودع الموقع

في مستودع الموقع:

```
Settings → Secrets and variables → Actions → New repository secret
```

```
Name: FONTS_TOKEN
Secret: (المفتاح الذي نسخته)
```

## ٤. النشر من الكود

في مستودع الموقع:

```
Settings → Pages → Build and deployment → Source: GitHub Actions
```

وفي الصفحة نفسها تأكد أن الدومين ما زال مكتوباً، وأن خيار الاتصال الآمن مفعّل:

```
Custom domain: alzahmah.com
Enforce HTTPS: ✓
```

## ٥. أخبرني

قل لي «ارفع»، فأرفع المشروع إلى المستودع مع الإبقاء على ملفاتك المؤقتة في سجله، فيُبنى الموقع ويظهر على الدومين خلال دقائق. كل رفع بعد ذلك ينشر الموقع تلقائياً.

## ملاحظات

- في كلاودفلير اترك سجلات الدومين بالسحابة الرمادية، أي بلا وكيل، حتى تصدر شهادة الاتصال الآمن من GitHub.
- المفتاح ينتهي بعد سنة. قبل انتهائه أنشئ مفتاحاً جديداً واستبدله في الخطوة الثالثة.
- البطاقة الرقمية في مستودعها الخاص بها، ولا تتأثر بهذا المستودع.
- الزوار يرون الآن صفحة «قريباً» فقط. لترى الموقع كاملاً من متصفحك افتح هذا الرابط مرة واحدة:

```
https://alzahmah.com/?preview
```

  ولترى ما يراه الزوار مرة أخرى:

```
https://alzahmah.com/?public
```

- الموقع مخفي عن محركات البحث حتى الإطلاق، والمفتاح في هذا الملف:

```
src/i18n/ui.ts → launched
```

- عن الترخيص: الموقع المنشور يعرض الخط كجزء من الموقع المبني، وهذا ما يسمح به الترخيص. أما المستودع الخاص فهو مكان تخزين لا يصل إليه أحد غيرك، لكن نص الترخيص يمنع رفع الخط إلى أي منصة رقمية، فقد يُفهم أنه يشمل المستودع الخاص أيضاً.
